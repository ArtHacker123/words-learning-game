# 词域攻防 · 植物大战单词

本地单机 PvZ 风格背单词游戏:五幕逐幕推进(教学 → 演练 → 复习浪 → 头目 → 终局),点选育苗盘卡片"射击"即回忆;全通关且基地无损每天可得钻石,跨天累计。当天要复习的词较多时**自动分块为一局局小局(每局 ≤ 15 词)**,逐局打完即覆盖全部待复习词。

纯本地运行,无后端,进度保存在浏览器 IndexedDB(刷新/次日重开不丢)。

## 环境要求

- Node.js ≥ 20.19(建议 22+)
- 推荐使用包管理器 `npm`(仓库已锁定 `package-lock.json`)

## 启动与访问

```bash
npm install     # 首次安装依赖(已在仓库外,不在本目录则先进入本项目目录)
npm run dev     # 启动开发服务
```

启动后在终端会打印访问地址,**默认 http://localhost:5173/**。若 5173 端口被占用,Vite 会自动顺延(如 http://localhost:5174/),以终端实际打印为准,直接浏览器打开即可。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 启动开发服务(带热更新),地址见终端输出 |
| `npm run build` | 类型检查 + 生产构建,产物输出到 `dist/` |
| `npm run preview` | 本地预览构建产物(默认 http://localhost:4173/) |
| `npm run test` | 运行全部单元测试(当前覆盖战斗/调度/奖牌等) |
| `npx tsc --noEmit` | 仅做 TypeScript 类型检查 |

## 玩法速览

1. 首次进入先**导入词表**:每行一条,格式 `外语,中文`(如 `apple,苹果`);也可跳过导入直接试玩。
2. 点「开一局」生成今日计划,展开 **第 1~5 幕**:幕内僵尸携带单词向左推进,射它等于回忆它。
   - 当日复习词 ≤ 15 就是 1 局;超过会切成多局,主菜单显示「第 k/n 局」进度,一局胜利后直接点「下一局」连打,失败则重打当前局,全部打完即完成当日复习。
3. **育苗盘**内点选一张卡(回忆候选)→ 点某条车道的空格种植 → 植物持续装弹,点植物再点目标僵尸即可开火。
   - 标签与僵尸身体上的词匹配 → 命中(僵尸掉血 + 阳光 + 连击);不匹配 → 植物哑火 3 秒、僵尸加怒变强。
   - 僵尸到岸边会**围攻基地**(每 2 秒咬一口),基地血归零即本幕失败、原地重打。
4. **第 5 幕终局**:一只跨车道接力 boss,分多个词段轮换,打空每段换下一个词,全段打空才通关。
5. 通关时若**基地满血(未受损)** → 奖励 💎 1 颗,每天最多 1 次,总数跨天累计,显示在左上角。
6. 「次日」推进到新一天,词表按记忆情况(SRS 间隔阶梯)自动安排复习与新词。

## 游戏内提示

- 升级面板(HUD「升级」按钮):阳光可买 急速装填 / 破甲弹药 / 自动发射 / 凝固弹,本局有效。
- 词表随时可扩充:主菜单「导入更多词」继续追加。
